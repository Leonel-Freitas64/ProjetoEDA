◆ limpartela()

void limpartela ( )

Limpa a tela do terminal.

Esta função utiliza comandos do sistema operacional para limpar a tela do terminal. No Windows, o comando "cls" é usado, enquanto no Unix/Linux/MacOS, o comando "clear" é utilizado. O operador "||" garante que o comando correto seja executado dependendo do sistema.
